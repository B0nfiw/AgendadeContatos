# Agenda de Contatos

Aplicação de estudos em HTML, CSS e JavaScript para adicionar nomes e telefones a uma tabela de contatos.

## Funcionalidades

- Cadastro de nome e telefone pelo formulário.
- Verificação de preenchimento dos campos.
- Remoção de caracteres não numéricos do telefone.
- Formatação de números com 11 dígitos.
- Limpeza dos campos após a inclusão.

## Como executar

1. Clone o repositório:
   ```sh
   git clone https://github.com/B0nfiw/AgendadeContatos.git
   ```
2. Abra `index.html` no navegador.
3. Preencha nome e telefone e envie o formulário para adicionar uma linha.

Não há dependências a instalar nem etapa de build.

## Tecnologias e estrutura

- `index.html`: formulário e tabela de contatos.
- `style.css`: estilos da interface.
- `index.js`: inclusão de contatos e formatação de telefone.

## Limitações atuais

Os contatos ficam apenas na página e são perdidos ao recarregá-la. Não há backend, armazenamento persistente ou funções de edição e exclusão.
